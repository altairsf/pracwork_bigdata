Trabalho prático da disciplina Tecnologias para desenvolvimento de soluções de Big Data do Curso Desenvolvimento Full Stack - Universidade Estácio
O objetivo é mostrar como tratar os dados de um conjunto a fim de que possam ser utilizados para a descoberta de conhecimento através de sua posterior
análise e interpretação. O conjunto de dados que serve de base para a prática está no arquivo PicoWeb.csv na pasta "Dados".
A atividade prevê a ocorrência de erros no tratamento de dados que devem ser solucionados por meio da regularização e tratamento. Os erros apareceram,
como mostrados nas imagens contidas no projeto.
